# AKRE — Commerce Intelligence

Browser-based AKRE frontend. This is the preserved MVP UI foundation for the production platform.

## Current scope
The UI includes Radar, Products, Suppliers, Store, Content, Experiments, Analytics and Settings views. Radar currently uses clearly labeled demo data.

## Production layer to build
- Permitted trend-data sources
- Supplier API/feed adapters
- Shopify Admin API
- Meta/Instagram APIs
- Authentication
- PostgreSQL or managed database
- Background job scheduler
- Experiment/event tracking
- Real order/returns data

The current UI does not simulate live integrations or spend money.
